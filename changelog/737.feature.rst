Add :meth:`PluginManager.register_many() <pluggy.PluginManager.register_many>` which registers an ordered batch of plugins atomically: the whole batch is validated first (marker parsing and hookspec checks, without calling hook implementations or replaying historic calls), and only if every plugin validates is the batch published at once, with ``tryfirst``/``trylast``/``wrapper`` ordering identical to sequential :meth:`~pluggy.PluginManager.register` calls. If a historic-call replay raises after publishing, the exception propagates with the batch left registered.
